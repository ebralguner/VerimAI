# VerimAI

## Yapay Zeka Destekli Verimlilik ve Anomali Analiz Sistemi

VerimAI, işletmelerin üretim, satış, kârlılık ve operasyon süreçlerini analiz ederek daha hızlı, verimli ve doğru kararlar almasını sağlayan yapay zeka destekli bir analiz platformudur.

Bu sistem sayesinde:

- Üretim tahmini yapılabilir
- Satış analizi gerçekleştirilebilir
- Kârlılık hesaplanabilir
- Kanal karşılaştırmaları yapılabilir
- Anomali tespiti gerçekleştirilebilir
- Senaryo analizleri oluşturulabilir

---

## Projenin Amacı

İşletmelerde dağınık halde bulunan verileri tek panelde toplayarak:

- verimliliği artırmak,
- karar süreçlerini hızlandırmak,
- maliyet analizlerini kolaylaştırmak,
- riskleri erken tespit etmek

amaçlanmıştır.
